# Step 16 交付物：导出任务批量删除前端能力（2026-04-27）

## 1. 本步目标

1. 前端支持单个导出任务删除。
2. 前端支持本页全选与批量删除。
3. 删除后自动刷新导出任务列表并清理选中状态。

## 2. 前端改造

变更文件：

1. `frontend/src/api/client.ts`
2. `frontend/src/views/DashboardView.vue`

新增能力：

1. API：
- `deleteExportTask(exportId)`
- `batchDeleteExportTasks(exportIds)`

2. 导出任务面板：
- 新增“选择”列复选框
- 新增“全选本页”按钮
- 新增“批量删除”按钮
- 每行新增“删除”操作

3. 交互逻辑：
- 翻页或刷新后自动过滤无效选中项
- 批量删除后清空选中并刷新列表

## 3. 验证建议

1. 勾选多条导出任务，点击“批量删除”。
2. 校验提示文案中的成功/失败数量。
3. 执行单条删除，确认列表即时刷新。
4. 翻页后确认选中态不会污染其他页面。
