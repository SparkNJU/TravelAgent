更新时间：2026-06-09

## 1. 项目范围

本次会话主要集中在：

- `agent`

- `frontend`

`evaluator` 目录不作为本次优化范围，后续新对话默认可忽略。

## 2. 这次要解决的核心目标

围绕前端做整体优化，重点是：

- 首页改成 3D 地球主视觉
- 非首页采用侧边栏布局
- 首页无侧边栏，其他页面显示侧边栏
- 发现页、AI 规划页、模型排行榜页、我的入口的导航重构
- 模型排行榜风格靠近 arena.ai，但整体配色保持红白
- AI 规划对话区和消息输出 UI 优化
- 地球视觉要更接近“透明地球 + 大陆轮廓 + 标点随球体旋转”的效果

## 3. 已完成的主要改动

### 3.1 布局与导航

- 去掉了顶部栏式主导航。
- 首页 `/` 现在是独立首页，不显示侧边栏。
- 其他页面显示左侧侧边栏，风格参考小红书布局。
- 侧边栏包含：
  - 发现
  - AI 规划
  - 发布笔记
  - 模型排行
  - 我的
  - 底部头像 / 昵称
  - 深色 / 浅色模式切换
- “我的”入口从顶部导航逻辑中移除，改为登录后头像下拉相关入口。

### 3.2 首页 3D 地球

- 首页改为全屏地球首屏。
- 地球是独立视觉模块，不再依赖右侧重复 AI 规划区域。
- 增加了“探索”按钮，点击后跳转到发现页。
- 地球当前目标风格：
  - 透明球体
  - 有边框
  - 仅保留大陆轮廓
  - 标点为简单红点
  - 标点随地球转动
  - 视角偏直视

### 3.3 模型排行榜

- 模型排行榜已改为红白主色。
- 布局参考 arena.ai 的排行榜结构：
  - 左侧指标筛选
  - 中间排行表
  - 右侧信息区
- 不采用深色主体风格。

### 3.4 AI 规划对话区

- 对话历史、消息气泡、流式输出样式做过优化。
- 去掉了重复的右侧 AI 规划区域。
- 对话布局更偏向正式工作台风格。
